A fully functional e-commerce simulation built using core Data Structures:
- **Linked List** — Cart management
- **Binary Tree** — Product categorization
- **Queue (FIFO)** — Order processing
- **Hash Table** — Fast product lookup (O(1) average)

### 2. Browser Simulator
A command-line browser simulator that models real browser navigation:
- **Stack (LIFO)** — Forward/back navigation history
- URL tracking and session management
- Replicates core browser mechanics through pure DSA

## 🚀 Deployment

This site is deployed via **GitHub Pages**.

To deploy your own copy:
1. Fork this repository
2. Go to **Settings → Pages**
3. Set source to **main** branch → `/ (root)`
4. Your site will be live at `https://yourusername.github.io/Task1_Bahadur-ali_decodelab/`
